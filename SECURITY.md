# Security Policy

## Reporting

Please report security issues privately to the project maintainer before publishing exploit details. Include the affected version, impact, reproduction conditions, and a minimal proof of concept when appropriate.

## Scope

Useful reports include unintended command execution, unsafe parsing of BLE input, permission/privacy problems, leaked secrets, insecure release configuration, or crashes caused by malformed frames.

## Safety

Test against hardware you own or are authorized to use, preferably with the scooter stationary and supported. Remove Bluetooth addresses, account information, and other personal identifiers from logs before sharing them publicly.
